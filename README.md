# 🏠 House Price Prediction

## 📌 Project Overview

This project focuses on predicting house prices using Machine Learning regression techniques.

The goal is to build a machine learning pipeline that takes house-related features as input and predicts the house price.

## 📊 Dataset

The dataset contains information about houses, including features such as:

- Number of bedrooms
- Number of bathrooms
- Living area
- Lot area
- Year built
- Location-related features
- Other house characteristics

The dataset is stored in `data-selected-columns.csv`.
